# routing5: longest prefix match
#
# routes.txt is a laptop's routing table. For every destination the kernel
# picks the route with the LONGEST matching prefix (/24 beats /22 beats /16
# beats /0 = default), no matter in which order the lines appear. Metrics only
# break ties between routes with the same prefix.
#
# For each destination write the next hop: the gateway address after "via",
# or the word `direct` for a "dev ... scope link" route (no gateway; the host
# itself is on that wire), or `blackhole` if the packet is silently dropped.
#
# Want to check yourself? In `netlings sandbox routing5` you can rebuild the
# table with dummy interfaces and ask `ip route get ADDRESS`. That is how the
# pros do it too.

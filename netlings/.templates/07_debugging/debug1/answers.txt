# lookup and a few TCP connections to 10.0.0.2. How to read a TCP line:
#
#   TIME IP SRC.PORT > DST.PORT: Flags [..], seq .., ack .., length N
#
#   Flags: S = SYN (open), . = ACK, P = PUSH (data), F = FIN (close),
#          R = RST (reset: "go away"). [S.] is SYN+ACK.
#   A connection starts with the three-way handshake: [S], [S.], [.]
#   A port with nothing listening answers a SYN with [R.] right away.
#   A firewall that DROPS gives no answer: the client retries the SYN,
#   waiting longer each time (1s, 2s, 4s, ...).
# DNS lines: "12345+ A? name." is a query; "12345* 1/0/0 A 1.2.3.4" is the answer.
